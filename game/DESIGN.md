# 게임 정체성 (Design Pillars)

> 이 문서는 "무엇을 만들 것인가"의 기준선입니다.
> 앞으로 모든 기능 추가는 **"이게 아래 기둥 중 무엇을 강화하는가?"** 로 판단합니다.
> 어느 기둥도 강화하지 않는 기능은 재미있어 보여도 넣지 않습니다.

---

## 한 줄 정의

> **바닥 패턴을 읽으며 버티다가, 쿨다운이 차면 터뜨리는,
> 손으로 숨긴 비밀이 있는 반(半)오픈 쿼터뷰 액션 RPG**

## 세 게임에서 무엇을 가져왔는가

| 참조 | 가져온 것 | **버린 것** |
|---|---|---|
| **로스트아크** | 스킬 로테이션 · 바닥 장판(AoE) 회피 · 포지셔닝(백어택) | MMO · 무한 파밍 · 숙제 |
| **No Rest for the Wicked** | 스태미나 · 회피 구르기 · 공격 커밋(무게감) · 수직 지형 | 극악한 난이도 · 생존/제작 관리 |
| **검은 신화: 오공** | 와이드 리니어 레벨 · 손으로 숨긴 보물 · "헤매지 않는 탐험" | 완전 3인칭 · 대규모 제작비 |

## 기둥 1 — 두 자원, 두 리듬 ⭐ 핵심 차별점

**문제:** 로스트아크식 스킬 전투와 소울라이크 스태미나 전투는 그냥 합치면 서로를 죽입니다.

조사로 확인한 두 게임의 실제 설계:

| | 로스트아크 | 소울라이크 |
|---|---|---|
| 자원 | **쿨다운** (시간) | **스태미나** (행동) |
| 회피 | 대시. **쿨다운 약 10초** | 구르기. 스태미나만 있으면 언제든 |
| 리듬 | 화려한 폭발 | 신중한 견제 |

- 스킬에 스태미나를 물리면 → 스킬 쓸 때마다 회피 자원이 사라져 **답답해집니다.** 로아의 시원함이 죽습니다.
- 회피를 로아처럼 10초 쿨다운으로 만들면 → **매 순간의 판단**이 사라집니다. 소울라이크가 죽습니다.

**해법: 두 자원을 분리합니다.**

| 자원 | 사용처 | 출처 |
|---|---|---|
| **스태미나** | 기본 공격 콤보 · 회피 구르기 | NRFTW |
| **쿨다운** | 스킬 4슬롯 (Q · E · R · F) | 로스트아크 |

**그러면 전투에 저절로 리듬이 생깁니다:**

```
쿨다운 도는 중  →  【소울라이크 구간】 기본공격·회피로 버티며 스태미나 관리
쿨다운 찬 순간  →  【로스트아크 구간】 스킬 로테이션으로 터뜨림
```

**"버티다가 터뜨린다."** 이게 우리 전투의 정체성입니다.
어느 쪽 게임에도 없는 리듬이고, 둘 다의 장점을 죽이지 않습니다.

### 무기제를 택한 이유 (직업제가 아니라)

성장 설계와 직결된 결정이라 여기 남깁니다.

| | 로스트아크 = 직업제 | NRFTW = 무기제 |
|---|---|---|
| 스킬의 출처 | 직업 고정 | 무기 + 룬 |
| 발견한 보물이 할 수 있는 것 | **수치 강화뿐** | **새 플레이 방식** |

우리는 "보물 = 새로운 걸 할 수 있게 되는 것"으로 정했습니다(아래 성장 항목).
**직업제에서는 이게 성립하지 않습니다.** 다른 직업 스킬을 줄 수 없으니 결국
"공격력 +5%"가 되는데, 그건 우리가 명시적으로 버린 성장 방식입니다.
1인 개발 비용도 무기제가 낮습니다 — 직업 1개는 그 직업을 고른 사람만 쓰지만,
무기 1개는 모든 플레이어의 선택지가 됩니다.

**구조 (조합 폭발을 막는 절충):**

```
Q, E  ←  무기 전용 스킬     무기를 바꿔야 바뀜 → 정체성 · 밸런스 기준선
R, F  ←  룬 스킬 (자유)     탐험으로 획득       → 자유도 · 성장
```

완전 자유 조합(클래스리스)은 조합 폭발로 1인 개발자가 밸런스를 감당할 수 없습니다.
무기 슬롯을 고정해 기준선을 만들고, 자유 슬롯을 2개로 묶어 폭을 제한했습니다.

**현재 무기 3종:**

| 무기 | 성격 | 콤보 | Q | E |
|---|---|---|---|---|
| 롱소드 | 균형 | 3타 | 돌진 베기 | 회전 베기 |
| 대검 | 느리고 무겁다 | 2타 | 대지 강타(지점 지정) | 광폭 휘두르기 |
| 쌍단검 | 빠르고 약하다 | 4타 | 그림자 도약(무적 대시) | 연속 찌르기(5회) |

## 기둥 2 — 바닥을 읽는 전투

쿼터뷰를 고른 진짜 이유입니다. 카메라 각도를 52°로 눕힌 것도 이 결정에서 나왔습니다.

- 적의 공격은 **지면에 예고 도형**으로 먼저 그려집니다 (이미 구현됨)
- 로스트아크는 예고를 **색으로 구분**합니다 — 빨강/파랑/노랑/보라가 각각 다른 대응을 요구
- 우리도 색으로 구분합니다:

| 색 | 의미 | 요구되는 대응 |
|---|---|---|
| 🔴 빨강 | 직격 피해 | 회피 구르기 / 범위 밖으로 |
| 🟡 노랑 | 넓은 장판, 느림 | 걸어서 빠져나가기 |
| 🔵 파랑 | 경직/속박 | 반드시 무적 프레임 |
| 🟣 보라 | 강제 패턴 | 특정 위치로 이동 |

> **판단 기준:** 플레이어가 죽었을 때 **"내가 못 봤네"** 가 아니라 **"내가 못 피했네"** 라고 말해야 합니다.
> 전자는 설계 실패이고, 후자는 설계 성공입니다.

## 기둥 3 — 포지셔닝이 보상받는다 ✅ 구현 완료

로스트아크의 백어택을 가져옵니다 (조사 확인: 백어택 +치명타, 프론트어택 +피해).

| 수치 | 값 |
|---|---|
| 등 뒤 판정 부채꼴 | **120°** (적 후방 기준 좌우 60°) |
| 백어택 피해 | **×1.55** |
| 기본 치명타 확률 | 8% |
| 백어택 시 치명타 확률 | **+45% → 53%** |
| 치명타 피해 | ×1.8 |
| 최대 배율 | **×2.79** (12 → 33.5) |

**세 가지 설계 결정과 근거:**

**① 판정을 "공격 방향"이 아니라 "내가 선 위치"로 잽니다.**
공격 방향으로 재면 제자리에서 마우스만 돌려도 백어택이 터집니다.
그러면 이동해서 등 뒤를 잡는다는 이 기둥의 의미가 통째로 사라집니다.

**② 근접 부채꼴 공격에만 적용합니다.** 광역기(원형·지점 지정)에는 안 붙습니다.
광역기까지 보너스를 주면 "위치를 잡는 기술"이 아니라 **"장판을 크게 까는 기술"** 이
최적이 되어 기둥이 무너집니다.

**③ 적 → 플레이어 방향으로는 적용하지 않습니다.**
적이 여럿이면 플레이어는 한쪽만 볼 수 있습니다. 뒤에서 오는 추가 피해는
"실력으로 막을 수 있는 것"이 아니라 **피할 수 없는 소모**가 됩니다.
막기 방향 같은 대응 수단이 생기면 그때 대칭으로 되돌립니다.

**학습 장치:**
- 적에게 5.5m 안으로 들어가면 **등 뒤 구역이 지면에 표시**됩니다.
  없으면 백어택이 운처럼 느껴지고, 항상 켜두면 화면이 고리로 뒤덮입니다.
- 데미지 숫자에 **"백어택" / "백어택 치명타!"** 머리말이 붙습니다.
  색만 바꾸면 "왜 세게 들어갔지?"에 답이 안 됩니다. 글자로 알려줘야
  플레이어가 **다음에도 그렇게 하려고** 움직입니다.

> 이 기둥이 있으면 이동이 "도망"이 아니라 **"공격의 일부"** 가 됩니다.
> 그림자 도약(적을 뚫고 지나가는 무적 대시)이 "안 맞으려고 쓰는 것"에서
> **"때리려고 쓰는 것"** 으로 바뀌는 지점입니다.

## 기둥 4 — 헤매지 않는 탐험

오공의 설계 철학을 그대로 가져옵니다:
> *"긴장감을 유지하고, **헤매는 것을 줄이며**, 강점(보스전·전투)에 집중시킨다"*

- **와이드 리니어**: 주 동선은 명확. 하지만 곁길·막다른 길에 보상
- **보물은 손으로 숨깁니다.** 절차적 생성을 쓰지 않는 이유:
  > 비밀이 재미있는 건 **누군가 거기 일부러 숨겨뒀기 때문**입니다.
  > 알고리즘이 무작위로 뿌린 상자는 비밀이 아니라 그냥 랜덤 드랍이고,
  > 플레이어는 3분이면 알아챕니다.
- **미니맵 없음** (오공 방식). 대신 지형·조명·랜드마크로 길을 안내합니다

---

## 하지 않을 것 (명시적으로)

| 안 하는 것 | 이유 |
|---|---|
| 절차적 던전 생성 | 기둥 4와 정면 충돌 |
| MMO / 대규모 멀티 | 1인 개발 규모를 넘어섬 |
| 일일 숙제 · 피로도 | 우리가 좋아한 건 파밍이 아니라 **전투의 구성** |
| 적 100마리 떼거리 | 기둥 2·3과 충돌 (바닥을 읽을 수도, 등 뒤를 잡을 수도 없음) |
| 무기 제작 · 생존 관리 | 전투와 탐험에 집중 |

## 성장은 어떻게 하는가

파밍이 목적이 아니므로, 성장은 **전투의 선택지를 늘리는 방향**으로만 갑니다.

- 보물 = **새 스킬 / 스킬 변형** (수치 +5%가 아니라 **플레이가 바뀌는 것**)
- 예: "회피 구르기가 2회 연속 가능해짐", "3타 마무리가 광역이 됨"
- 즉 **"세져서 재미있다"가 아니라 "새로운 걸 할 수 있어서 재미있다"**

> 이게 파밍형 성장과 결정적으로 다른 점이고, 우리가 로스트아크에서
> **"파밍"이 아니라 "전투 구성"** 을 가져왔다는 선택의 논리적 귀결입니다.

## 현재 진행 상황

| 기둥 | 상태 |
|---|---|
| 1. 두 자원, 두 리듬 | ✅ **완료** — 스태미나(기본기·회피) / 쿨다운(스킬 4슬롯) 분리 |
| 2. 바닥을 읽는 전투 | 🟡 적 예고 부채꼴 + 스킬 지면 예고(테두리→차오름→발동) 완료 / **적 공격의 4색 구분 미구현** |
| 3. 포지셔닝 보상 | ✅ **완료** — 백어택 ×1.55 · 치명타 · 등 뒤 구역 표시 |
| 4. 헤매지 않는 탐험 | ✅ **완료** — 에디터 · 높이 지형 + 첫 존 「무너진 성문」 배포 |

### 기둥 4의 기술 토대는 완성되었습니다

- 높이맵 지형: 1단은 오르고 2단 이상은 절벽 → **벽 대신 높이로 길을 나눔**
- 내려가기는 항상 허용 → **일방통행 지름길** (되돌아가는 길을 여는 소울라이크식 장치)
- 쿼터뷰 가림 해소: 플레이어보다 2단 이상 높은 지형은 자동 반투명
- 손으로 배치하는 보물 · 적 · 보스 (에디터)

### 첫 존 「무너진 성문」 (176m x 144m)

```
                     [북쪽 단상 h3]  ← 1단 위, 막다른 길 (보물)
                           ↑
 [시작 광장] → [성문 통로] → [중앙 폐허] → [계단 h2→h3] → [보스 성벽 h4]
                    ↓              ↓                            (보물)
              [숨은 벽감]   [남쪽 함몰지 h0]
               (보물)        2단 낙하 = 되돌아갈 수 없음 (보물)
                                  └→ 복귀 램프 → 계단에 합류 (지름길)
```

- **주 동선은 항상 +X 한 방향** — 어디로 가야 할지 헷갈리지 않습니다
- 곁길 셋은 전부 주 동선에서 **보입니다.** 숨긴 것은 위치가 아니라 **"갈지 말지의 선택"** 입니다
- 남쪽 함몰지는 2단 낙하라 **못 올라옵니다.** 대신 복귀 램프가 계단으로 이어져 지름길이 됩니다
- 적 배치가 전투 동사를 순서대로 가르칩니다:
  좁은 통로(기본 콤보) → 넓은 폐허(광역기) → 단상 1:1(백어택) → 함몰지(퇴로 없음) → 보스

**방 크기 기준:** 카메라가 세로로 22m를 담으므로 모든 방을 최소 30m 이상으로 잡습니다.
첫 판에서 방을 작게 만들었더니 화면 절반이 허공으로 찼습니다.
